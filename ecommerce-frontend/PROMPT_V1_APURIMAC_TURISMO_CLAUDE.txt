============================================================ 1. CONTEXTO
DEL PROYECTO
============================================================

Estoy desarrollando un proyecto universitario para la asignatura de
Desarrollo de Aplicaciones Web con React y Node.js.

El proyecto asignado es:

“Reservas de hospedajes/turismo vivencial en Apurímac”

Responsable: Morón Luna, Jesús Alejandro.

IMPORTANTE: Esta es solamente la VERSIÓN 1 del proyecto.

Según la planificación del curso, en esta versión se debe trabajar: -
Frontend en React. - Datos de prueba/mock data. - Navegación entre
páginas con React Router. - Formularios funcionales, pero sin
persistencia real. - Diseño responsive. - Componentización. - Manejo de
estado con useState/useEffect cuando sea necesario. - Coherencia y
calidad de UI/UX.

NO implementar todavía: - Backend Node.js/Express. - API REST real. -
Base de datos. - MongoDB/PostgreSQL/MySQL. - Autenticación real. - Login
conectado a servidor. - Pagos reales. - Persistencia real. - Servicios
externos que requieran backend.

La arquitectura debe quedar preparada para que posteriormente pueda
agregarse backend, base de datos, autenticación y pagos sin tener que
rehacer completamente el frontend.

============================================================ 2. IDEA
GENERAL DEL PRODUCTO
============================================================

NO quiero crear simplemente una página de hoteles.

La idea es construir una plataforma moderna de turismo de Apurímac que
combine:

1.  DESCUBRIMIENTO DE DESTINOS.
2.  EXPERIENCIAS TURÍSTICAS.
3.  TURISMO VIVENCIAL.
4.  HOSPEDAJES.
5.  RESERVAS.

La propuesta conceptual es:

“Descubre Apurímac de una forma diferente.”

La plataforma permitirá que un visitante pueda descubrir lugares y
experiencias de Apurímac y, dependiendo de la experiencia, encontrar
hospedajes relacionados y realizar una reserva simulada.

Ejemplo:

Un usuario quiere conocer Choquequirao.

Puede encontrar: - Información de la experiencia. - Duración. -
Categoría. - Actividades. - Hospedajes relacionados. - Precio
referencial. - Fecha. - Número de personas. - Opción para reservar.

También debe existir la posibilidad de explorar hospedajes de manera
independiente.

Por lo tanto, el producto tendrá dos grandes caminos:

A)  EXPERIENCIAS Descubrir una experiencia → ver detalles → seleccionar
    fecha/personas → reservar.

B)  HOSPEDAJES Explorar hospedajes → ver detalle → seleccionar
    fecha/personas → reservar.

La reserva será simulada en V1. No debe realizarse ningún pago real.
